`jfk.wav` is the 16 kHz mono PCM sample from whisper.cpp v1.9.4:
https://github.com/ggml-org/whisper.cpp/blob/v1.9.4/samples/jfk.wav

It contains an excerpt from John F. Kennedy's January 20, 1961 inaugural address,
a US federal government work in the public domain. It is packaged only in the
test APK. The native inference test requires the Tiny English model installed
in the target app; the other device tests do not download models.
